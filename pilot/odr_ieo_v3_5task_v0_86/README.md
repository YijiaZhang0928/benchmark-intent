# Five-task IEO-v3 strict-cold-start batch

This package expands the single T09 replication to five preselected released task/persona rows.
The protocol and executable assets were committed before generation. All five pairs are now complete;
see [`RESULTS.md`](RESULTS.md) and [`evaluation/results.json`](evaluation/results.json). Mean paired
`ΔP_strict` is +0.9870, while macro `ΔRecall@AskableHigh` is −0.010, so final-report improvement did
not validate the intended clarification-recall mechanism.

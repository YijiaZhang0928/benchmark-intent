# RAW50 clarification target audit

This is a single-author process diagnostic. An axis is counted once per task when at least one field explicitly names it or operationalizes the decision needed for it. Multiple fields on one axis do not increase coverage. Broad catch-all fields are not credited by themselves.

## Counted high-impact axes

| Task | High-impact axis | Triggering field(s) | Coding note |
|---|---|---|---|
| T01 | P3 career utility | `career_goal` | Explicit post-PhD career choice |
| T01 | P4 program economics | `constraints` | Explicit funding, budget and language-constraint prompt |
| T02 | P2 interdisciplinary content | `academic_goal` | Options distinguish media/public-opinion/cross-cultural aims from methods-only study |
| T02 | P5 spending style | `budget`, `funding_priority` | Operationalizes cost/funding sensitivity, but does not elicit accommodation style |
| T03 | P1 venture projects vs another degree | `program_format` | Explicitly includes another degree and build-first route |
| T03 | P2 flexible format | `time_available`, `program_format`, `career_constraints` | Directly asks feasible time, formats and work/family constraints |
| T03 | P3 staged validation | `current_stage` | Operationalizes the user's current validation stage, but does not ask an abstract method preference |
| T03 | P5 resource allocation | `budget` | Explicit learning/program budget tiers |

Coverage is therefore T01 `2/5`, T02 `2/5`, T03 `4/5`, macro total `8/15`.

## Not counted

- T01 `ai_interests` selects a research topic but does not distinguish implementation-heavy from theory-only work.
- T01 `research_experience` records current experience but does not ask project-led versus coursework-led preparation preference.
- T02 institution, citizenship, timing, credit, partner, language and academic-record fields are eligibility/current-state variables.
- T02 the optional `constraints` field is too broad to earn preference-axis credit.
- T02 the second-turn proceed/assumption choice is a method decision, not a personalization preference.
- T03 startup sector, target market, funding route and language are task/current-state variables, not the frozen five high-impact axes.

Because P3 on T03 and P5 on T02/T03 are operational rather than clean value-contrast questions, `8/15` is a lenient upper diagnostic. A stricter “explicit preference contrast only” coding would be lower; no confirmatory claim relies on this count.

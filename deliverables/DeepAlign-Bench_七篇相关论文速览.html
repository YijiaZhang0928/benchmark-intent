01 · 用户理解

Setoka

Hierarchical User Understanding over Heterogeneous Data

arXiv:2607.27056 ↗
主图逻辑（重绘）
事实→事件→模式→特质
Abstract

把用户理解分成语义事实、情景记忆、行为模式和人格特质四层；用心理测量驱动的流程生成 10 个合成用户的异构记录，并评测 3 个模型与 5 个 memory system。

主图

异构记录 → selection → linking → aggregation → generalization；证据范围和推断抽象度逐级上升。

Conclusion / Limit

单记录事实可由数据库较好解决，但多记录拼接、长程聚合和人格推断仍弱；回答率高也可能是无依据猜测。

对 DeepAlign-Bench

给 user-state fact 保存 provenance 和推断层级；区别是我们评价这些推断是否让开放式 DR 交付物在 must-change 处正确变化。

不能再说“没有 benchmark 测跨源深层用户理解”。
02 · 时间干预

Temporal Interventions

User-Conditioned Evaluation under Temporal Interventions

arXiv:2607.21635 ↗
主图逻辑（重绘）
事件→持久→跨维→按用户
Abstract

focused audit / position paper：同一时间干预应在不同持久用户状态上重放，检查是否产生用户条件化差异。

主图

C1 显式外生事件；C2 状态跨事件持久；C3 一个维度影响另一个维度；C4 结果随用户状态变化。

Conclusion / Limit

审计的 15 个公开协议中，没有一个同时满足 C1–C4；建议提供 profile states、event scripts、dependency annotations、oracle checks 和 per-user regression suites。

对 DeepAlign-Bench

不能声称首次测试时间变化；要在 DR 最终交付物上实际满足 C1–C4，并增加反事实用户真值、正向效用和 judge 校准。

是我们 Update / Recover 设计最直接的方法学前作。
03 · 浏览历史

PersonaTrail

Personalized Web Agents through Browsing Trails

arXiv:2607.20482 ↗
主图逻辑（重绘）
轨迹→事实记忆→偏好记忆→网页行动
Abstract

在 managed open web 中，用细粒度浏览轨迹测试 preference inference 与 episodic grounding；覆盖 23 个领域、317 个网站和 2,524 个 query。

主图

同一 browsing history 分别支持“通常喜欢什么”和“过去某次看过什么”；前者需要 preference memory，后者需要 factual memory。

Conclusion / Limit

直接处理 raw history 不够；历史越多、任务越复杂，基线退化越明显。PACMem 的事实/偏好双记忆优于基线。

对 DeepAlign-Bench

把浏览/行为轨迹纳入 signal channel，并做 raw history 与语义等价 structured persona 的信息量匹配对照。

证明真实行为轨迹可以是用户信号，而不只是 persona 文本。
04 · 单域效用

TARS

Theory-of-Mind Personalized Code Comprehension

arXiv:2607.15948 ↗
主图逻辑（重绘）
用户画像→代码片段→适配解释→人类效用
Abstract

在 VS Code 内根据经验、角色、目标和解释偏好生成代码解释；18 人研究同时测时间、正确性、认知负担和主观适配。

主图

profiler questionnaire 把经验、角色、用途、长度、语言、目标和语气映射到解释生成。

Conclusion / Limit

平均完成时间约快 26%，认知负担与主观适配更好；但正确性几乎相同，时间差未过传统显著性门槛，外推仍有限。

对 DeepAlign-Bench

在少量 anchor 加 downstream human utility；不能把主观“感觉被个性化”当作客观任务收益。

提醒我们：个性化效用不应只看输出文字。
05 · 系统架构

SARSI

Governed Multi-Agent Architecture for Personal Singularity

arXiv:2607.12254 ↗
主图逻辑（重绘）
契约→执行→验证→治理
Abstract

提出 goal、scope、tool、benchmark 驱动的多 agent 架构，强调外部治理、owner control、可审计 self-model、任务契约和逐步升级。

主图

task-contract compiler → planner → tool actor/sub-agents → independent verifier；外部 governance 保留批准、回滚与关闭权。

Conclusion / Limit

反对单体 agent 自我改写后自我相信；主张版本化、可逆、外部授权。论文明确没有原创数据或实现。

对 DeepAlign-Bench

扩展 agent plane、handoff、责任主体、verifier 独立性和 rollback 元数据；不把架构主张写成性能结论。

可用于完善 ontology，但不是实证 benchmark 证据。
06 · 持久风险

PASB

Persistent Sycophancy in Stateful Personal Agents

arXiv:2607.10526 ↗
主图逻辑（重绘）
主张→写入→取回→污染
Abstract

1,600 个任务、12 个模型、2 个 agent framework；5 轮 persist 后清空对话，再用 3 轮中性 query 检查 agent 自主写入的状态是否污染后续。

主图

用户主张 → agent 接受 → durable write → 来源/状态变化 → 新会话取回 → 下游污染；write boundary 是关键。

Conclusion / Limit

commit 后平均失败从 45.0% 升至 71.9%（+27.0pp）；主要机制是 status promotion、attribution removal 和 scope broadening。

对 DeepAlign-Bench

将 source/status/scope/time/visibility 写入 metadata，并同时测正向 DR 适配、must-not 和共同质量。

是 state-writing safety 与 longitudinal failure 最强的直接前作。
07 · 意图利用

APeB

Agentic Personalization under Underspecified Product Search

arXiv:2607.03162 ↗
主图逻辑（重绘）
模糊意图→历史→偏好→细粒度选择
Abstract

从商品 action logs 构造原始欠指定 query、丰富历史和用户看过的 hard candidates，记录意图推断、偏好提取、检索和候选选择。

主图

agent 从视频、直播、浏览与搜索等历史推断意图，再在相近候选中选择；hard candidates 排除粗语义匹配的虚假高分。

Conclusion / Limit

明确 query 表现较好，早期意图与偏好发现较弱；history-aware query refinement 跨 backbone 带来一致增益。

对 DeepAlign-Bench

Ua/Ub 都必须合理且难以靠粗语义区分；中间 user-goal proxy 只做诊断，不能成为最终 judge 的循环真值。

证明 personalization gap 常在“欠指定意图 + 噪声历史”。

WHAT CHANGED

Proposal 1.1 现在应该怎么讲

从“没人测”改成“已有模块，缺少交叉识别”。

  1. 第一层：通用 DR benchmark 建立事实、搜索、引用和报告质量底线。
  2. 第二层：Setoka [26]、PersonaTrail [28]、APeB [32] 已经测用户理解与历史利用。
  3. 第三层：TARS [29]、PASB [31]、Temporal work [27] 已经触及单域效用、持久风险和时间变化。
  4. 第四层：PDR-Bench [4] 最接近个性化 DR，但仍缺 matched/swapped 反事实识别、预冻结差异真值与长程机制校准。
三项最低成立条件matched/swapped 人评稳定效应不由长度/风格/共同质量解释至少一个 signal/operator 效应可重复
